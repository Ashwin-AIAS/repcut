# Manual checks — the auto-edit (branch `feat/timeline-assembly`)

Only Ashwin ticks these. Deferred by amendment 016 until the build is done; the
order of the whole pass is in [VERIFY-LATER.md](VERIFY-LATER.md).

Make the artifacts first, from Git Bash in the repo, after STOP A and STOP B:

```
.venv/Scripts/python.exe scripts/fetch_models.py
.venv/Scripts/python.exe scripts/edit_review.py
```

It writes `$DATA_DIR/reviews/prompt-05/edit.html` and a 30 s edit (Moody theme,
the top-recommended track) from your real session in the library. The track is
generated by Repcut, not downloaded; drop your own royalty-free tracks into
`$DATA_DIR/music/` first if you want them considered.

### The edit has taste
- [ ] The cuts land where you would have cut, not merely where the beat is
      (watch the 30 s edit twice: once for the footage, once for the music)
- [ ] The drop opens on footage you would have put there
- [ ] No shot you would have thrown away (dead time, shake) made it in
- [ ] Nothing you would have kept is missing from the usable footage list
- [ ] Music ducks under speech without pumping, and comes back cleanly

### The controls do what they say
- [ ] In the editor: swap the track; unlocked cuts move to the new beat, a
      locked cut stays exactly where it was
- [ ] Remove a cut; a different shot takes its place and the edit stays on the beat
- [ ] "Export without music" leaves the edit beat-synced, with no track
- [ ] The track list says why each track was recommended, in words you agree with

### Real speech
- [ ] On a clip where you talk, the speech regions in the edit review match
      where you actually speak (the model has only been checked for false
      positives on music, noise and tone by the gate)
